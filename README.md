# A股资金流看板

每日主力资金流向复盘的可视化看板（纯静态，无依赖，适配手机）。

## 页面（顶部导航切换）

- `index.html` 今日整体：指标卡（今日净流入 / 近5日 / 流入流出板块 / 第一主线题材）、全市场近30日柱状、市场状态与宽度、今日流入/流出 TOP12、12日累计榜、轮动重合度
- `duanxian.html` 短线情绪：情绪分与阶段、连板高度分布、**题材主线榜（同花顺涨停板块：涨停家数 / 连板数 / 高度 / 代表股）**、**玄学炒作（"羊字辈"等按公告原文）**、涨停板块 TOP10、连板板块、高位板梯队（含题材归属）、**跌停/退潮板块**
- `qushi.html` 趋势波段：**主线监控（题材口径 × 行业资金印证）**、今日与12日板块资金榜、行业资金候选（旧口径）、已退潮板块
- `guojia.html` 国家队/ETF：ETF 净申购四个选项卡（全A / 宽基 / 行业 / 黄金）、沪深300ETF 二级市场主力净流入、每支 ETF 缩略图与热力图、监控 ETF 明细、个股 TOP10

## 文件

- `index.html` / `duanxian.html` / `qushi.html` / `guojia.html` 四个页面
- `assets/site.css` 共用样式，`assets/base.js` 共用工具与图表渲染
- `data.js` 页面数据（`window.DATA`），`sentiment.json` 当日情绪原始数据
- `data/sub_flow.json` ETF 净申购（一级市场）
- `export_data.py` 由本地资金流库生成 `data.js`
- `update_site.ps1` 每日 15:35 采集 + 导出 + 发布
- `collect_ths.py`（工作区 scripts）：同花顺涨停板块 / 涨停原因 / 玄学
- `.nojekyll` 关闭 GitHub Pages 的 Jekyll 处理

## 数据口径

- 资金：主力净流入＝超大单＋大单（东财行业板块 496 个），单位亿元；板块榜不含一级行业，市场总量按一级行业合计。
- 题材：同花顺涨停板块（概念）的涨停家数与连板数；子题材与主线涨停股重合≥70% 时合并，避免重复计数。行业板块的真实主导题材按涨停股重叠度计算。
- 玄学：同花顺个股涨停原因原文中出现"羊年/字辈/谐音/生肖/重名"等表述才标注，不臆测。
- 情绪：炸板率取整百分比，连板高度取整；炸板率>50% 且涨停环比腰斩时判为分歧而非修复。
- ETF 申赎：净申购＝(当日份额−前一日份额)×收盘价，份额取沪深交易所日度规模（T+1 确认），与二级市场主力净流入不是同一指标。
