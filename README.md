# A股资金流看板

每日主力资金流向复盘的可视化看板（纯静态，无依赖）。

## 内容

- 今日市场情绪（涨停/跌停/炸板/最高板/连板家数/情绪分与阶段）
- 今日短线情绪板块（涨停板块分布、连板板块、高位板梯队）
- 指标卡（今日净流入、近5日累计、三X状态、第一候选主线）
- 全市场主力净流入（近30日柱状）
- 今日净流入/净流出 TOP12
- 科技退潮后的接棒主线监控（含升级与失效条件）
- 12日累计资金榜
- 沪深300ETF 与监控 ETF 每日净流入（合计柱+累计线）
- 每支 ETF 每日净流入缩略图 + 每日×每支热力图
- 国家队/宽基与科技 ETF 明细、个股主力净流入 TOP10、已退潮板块、轮动重合度

## 文件

- `index.html` 页面（全部 CSS/JS 内联）
- `data.js` 页面数据（`window.DATA`）
- `sentiment.json` 当日市场情绪原始数据
- `export_data.py` 由本地资金流库生成 `data.js`
- `.nojekyll` 关闭 GitHub Pages 的 Jekyll 处理

## 数据口径

主力净流入＝超大单＋大单，东方财富行业板块（496 个），单位亿元。
板块榜不含一级行业；市场总量按一级行业合计。
